# CBM India Trust — Interactive Homepage Mockup

A modern, accessible, and editorial one-page homepage mockup for **CBM India Trust**, designed for disability inclusive development.

## 🌟 Key Features

- **Editorial & Contemporary Design:** Retains CBM's iconic crimson red (`#C5192D`), marigold yellow (`#FFB81C`), and clean white branding.
- **Unified 1-Screen Donation Console:** Simplifies multi-program, recurring vs. one-time giving, and 80G tax exemption calculations into a single, intuitive 2-column interactive module with a live impact mirror card.
- **Complete Accessibility Drawer:**
  - High Contrast mode
  - Highlight links
  - Larger text
  - Text spacing
  - Pause animations
  - Hide images
  - Dyslexia-friendly font (`Lexend`)
  - High-visibility enlarged cursor
- **Documentary Photography:** Authentic, dignified visuals representing CBM India's core pillars: Inclusive Education, Inclusive Livelihood, Inclusive Health, and Inclusive Humanitarian Action.
- **Interactive Modals:** Stories of change reader modals, video modal preview, and mobile navigation drawer.
- **Responsive:** Optimized for viewports from desktop (`1440px`) to mobile (`390px`).

## 🚀 How to Run Locally

You can preview this project in any modern web browser:

1. **Option 1 (Node Server):**
   ```bash
   node server.js
   ```
   Open `http://localhost:3000` in your browser.

2. **Option 2 (Direct):**
   Double-click `index.html` to open it directly in your browser.
